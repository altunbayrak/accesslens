# LinkedIn launch post

I built AccessLens because “the site looks fine” is not a release criterion.

AccessLens turns an authorized website audit into an actionable quality report: WCAG-oriented accessibility checks, performance signals, metadata and broken-link checks, passive security-header review, screenshots, and evidence developers can use.

The key design choice is security-first: every target and redirect is allowlisted, private and cloud-metadata addresses are blocked, and the browser worker runs in isolation. It is built for sites you own or are explicitly permitted to audit.

The stack is Next.js, FastAPI, PostgreSQL, Redis, Playwright, axe-core, Lighthouse, Docker, and GitHub Actions.

The goal: give product teams a clearer signal before problems become customer issues.
